# Seaborn Data Visualization – Titanic Dataset

## 📊 Project Overview

This project demonstrates data visualization techniques using **Python, Pandas, Matplotlib, and Seaborn**.
The **Titanic dataset** is used to explore passenger information through different statistical and graphical visualizations.

## 🛠️ Technologies Used

* Python
* Seaborn
* Matplotlib
* Pandas
* Jupyter Notebook

## 📈 Visualizations Included

The notebook contains the following visualizations:

* **Joint Plot** – Fare vs Age
* **Histogram** – Distribution of Fare
* **Box Plot** – Class vs Age
* **Swarm Plot** – Age distribution across passenger classes
* **Count Plot** – Male vs Female passengers
* **Heatmap** – Correlation matrix of numerical features
* **FacetGrid** – Age distribution by gender

## 📂 Dataset

The project uses Seaborn's built-in **Titanic dataset**, loaded directly using:

```python
sns.load_dataset('titanic')
```

The dataset contains information about Titanic passengers, including age, fare, gender, passenger class, and other attributes.

## 🎯 Objective

The main objective of this project is to understand how Seaborn can be used to:

* Explore data visually
* Identify patterns and distributions
* Compare different groups
* Analyze relationships between numerical variables
* Understand correlations between features

## 🚀 How to Run

1. Install the required libraries:

```bash
pip install seaborn matplotlib pandas jupyter
```

2. Open the notebook in Jupyter Notebook or JupyterLab.

3. Run the cells sequentially to generate the visualizations.
